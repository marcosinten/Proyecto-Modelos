# Vista anterior (respaldo)

Copia congelada de `web/src` antes del rediseño completo de noviembre de 2026.
Se abre con `?vista=anterior` (por ejemplo `http://127.0.0.1:5173/?vista=anterior#monitor`).
No se mantiene: cuando el rediseño se apruebe, esta carpeta se puede borrar.
Las rutas relativas (`../../compartido`, `../../ejemplos`) siguen funcionando porque está a la misma
profundidad que `web/src`; el modelo 3D se toma de `web/src/assets`.
